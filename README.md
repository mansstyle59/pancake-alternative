# Pipeline Pilot — Prospection B2B

Prototype indépendant en français pour organiser la prospection commerciale, inspiré des workflows généraux des outils de prospection B2B. Ce projet n'est ni affilié à Pancake.ai ni une copie de son code ou de sa marque.

## Démarrage
Ouvrez `index.html` dans un navigateur moderne. Aucune installation ni clé API n'est nécessaire.

## Fonctions
- Tableau de bord commercial
- Gestion locale des prospects, score et statuts
- Campagnes de prospection
- Profil du client idéal (ICP)
- Génération de brouillons de messages personnalisés
- Copie des messages et export CSV
- Interface responsive mobile / ordinateur

## Limites importantes
Cette version est un prototype front-end. Les données sont conservées dans le `localStorage` du navigateur et ne sont pas synchronisées entre appareils. Aucun scraping, enrichissement externe, modèle IA distant, CRM, authentification ou envoi de messages n'est connecté. Les textes générés sont des modèles à vérifier, pas des données vérifiées.

Avant un usage professionnel, ajouter une API serveur sécurisée, une base de données avec authentification, des sources de données autorisées, la gestion des consentements/oppositions et des tests.

## Technologie
HTML, CSS et JavaScript natifs. Pas de dépendance ni de build requis.
